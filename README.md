# Kombat Database Bot

Telegram-справочник по мобам, ресурсам, снаряжению, картам и рецептам. Бот работает на `aiogram 3`, хранит данные в SQLite и собирает встроенную аналитику.

## Требования

- Python 3.10–3.13;
- токен Telegram-бота;
- постоянный диск для SQLite в production.

## Запуск

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt

$env:BOT_TOKEN = "<telegram-token>"
$env:ADMIN_ID = "123456789,987654321"
$env:DATABASE_PATH = "game.db"
python bot.py
```

При первом запуске актуальная схема и все индексы создаются автоматически. Перед подключением бота база проверяется по версии схемы. Если версия устарела, приложение само создаёт backup, переносит все данные в новую схему, проверяет результат и только затем запускает polling.

## Автоматическая миграция данных

Отдельная консольная команда для штатного обновления не нужна. После обновления контейнера обычный запуск:

```text
python bot.py
```

автоматически:

1. проверяет версию схемы до открытия основной SQLite-сессии;
2. ничего не делает, если версия актуальна;
3. при устаревшей версии создаёт backup с timestamp, SHA-256 и JSON-манифестом;
4. переносит все строки в новую схему и проверяет их, внешние ключи и целостность;
5. атомарно заменяет рабочий файл и продолжает запуск бота.

Если проверка или перенос завершаются ошибкой, исходная база не заменяется, а запуск бота прекращается с записью причины в лог контейнера.

`DATABASE_PATH` и `DATABASE_BACKUP_DIR` должны указывать на постоянное хранилище контейнера, чтобы база и backup-копии переживали пересоздание контейнера.

Ручная команда остаётся только для восстановления из конкретной backup-копии:

```powershell
python scripts/migrate_database.py "C:\path\to\game.db" --source-backup "C:\path\to\backup.db" --yes
```

Каталог `backups/` и SQLite-файлы исключены из Git, так как могут содержать production-данные.

## Переменные окружения

| Имя | Обязательна | Описание |
| --- | --- | --- |
| `BOT_TOKEN` | да | Токен от BotFather |
| `ADMIN_ID` | нет | Telegram ID администраторов через запятую |
| `DATABASE_PATH` | нет | Путь к SQLite, по умолчанию `game.db` |
| `DATABASE_BACKUP_DIR` | нет | Каталог backup-копий, по умолчанию рядом с базой в `backups/` |
| `DATABASE_BACKUP_KEEP` | нет | Количество хранимых backup-копий, по умолчанию `10` |

Файл `.env.example` служит шаблоном. Проект не читает `.env` автоматически: передавайте переменные через shell или панель хостинга.

## Тесты

```powershell
python -m unittest discover -s tests -v
```

Тесты проверяют создание схемы, перенос данных и backup, транзакции, конкурентные вставки, каскадную очистку и разбор callback/deep-link данных.
